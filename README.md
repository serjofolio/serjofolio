#### [TikTok 运营台](https://github.com/serjofolio/tiktok-ai-ops) · [在线体验](https://tkagent.hyff.cc.cd)

AI 驱动的 TikTok 跨境电商全链路运营系统。把选品、找货、上架、内容这几个岗位的工作交给多 Agent 流水线接力完成，人只在关键节点做决定。

- 🎯 **多维度选品**：六维评分 + AI 研判报告，规则先拦住侵权、刷单、类目受限等硬伤
- 🔍 **1688 找货比价**：AI 提炼中文搜索词、以图搜、权重比价矩阵、同款判断、利润倒推
- ✍️ **AI 上架包**：东南亚本地语言 + 英文资料，违禁词检查，按目标利润定价，一键推送 ERP
- 🧩 **Chrome MV3 插件**：没有官方接口也能自动搜索、以图搜、采集，内置防风控节奏
- 🛡️ **多账号隔离**、IP 直连封禁、Cloudflare 隧道部署；24 个 Playwright 端到端用例
